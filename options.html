Privacy & Security Notice

  • Local Storage: Your API key is stored strictly within your browser's local extension storage (chrome.storage.local).
  • No Intermediary Servers: API requests are sent directly from your browser to your configured provider. ContextSense has no external backend, telemetry, or third-party servers.
  • Minimal Context: Only the selected word and the immediate enclosing sentence/paragraph are sent to the AI model to infer contextual meaning. Full web pages and conversations are never read, sent, or saved.
  • API Costs: Direct API calls consume tokens billed to your API provider account. Please note that a standard ChatGPT Plus or Team subscription does not include OpenAI API platform credits.
  • DOM Safety: Your API key is never injected into web pages or accessible to page scripts.
